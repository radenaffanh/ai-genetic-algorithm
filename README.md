# Genetic Algorithm

Genetic algorithm in Python with binary chromosomes, roulette-wheel selection and one-point crossover.

## Features

- Binary-encoded chromosomes decoded to decimal values
- Fitness function to maximise
- Roulette-wheel selection and one-point crossover

## How to run

```bash
python genetic_algorithm.py
```
